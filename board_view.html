Protrusion Test Board

The Phase 1 bench for the slide-protrusion project: seven bolts set to caliper-measured heights, four ArUco markers at ruler-measured positions. Drag to orbit, scroll to zoom. Move the light low to see what a grazing-light photo has to work with.

Low light stretches each bump into a shadow. 90° is straight overhead.
1× is true scale. Raise it only to see the shapes.
